### Stress Performance Testing Exercise

Install and run a stress performance testing tool (Apache JMeter, Grafana k6, Locust...).

1. Try testing HTTP requests against a public website (e.g., https://www.landonhotel.com) as a load test.<br>
   **Use a small or average load.**<br>
   **Do not stress a public website. It will look like a DoS attack**

2. Test a web application of your own. Implement the following:
   - Load testing
   - Stress testing
   - Spike testing
   - Soak testing

If you are using Apache Meter:
- Install and run it: (https://jmeter.apache.org/)
- Go to https://jmeter-plugins.org/. Download and install the plugin Custom Thread Groups
- To implement the four types of test, use the threads model `jp@gc - Ultimate Thread Group`
